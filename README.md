# Suécia Premium cars - Website

Este é o projeto completo do site da Suécia Premium cars, construído com Next.js, Tailwind CSS e Framer Motion.

## Tecnologias Utilizadas
- **Next.js 14** (App Router)
- **React 18**
- **Tailwind CSS** (Estilização baseada em utilitários)
- **Framer Motion** (Animações fluidas)
- **Lucide React** (Ícones)
- **TypeScript**

## Como rodar o projeto localmente

Como o Node.js parece não estar instalado neste ambiente, você precisará instalá-lo primeiro.

1. Baixe e instale o Node.js (versão LTS recomendada): https://nodejs.org/
2. Abra o terminal nesta pasta (`suecia-premium-cars`)
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra no navegador: `http://localhost:3000`

## Estrutura do Projeto
- `/src/app`: Rotas e layout principal (Next.js App Router)
- `/src/components`: Todos os componentes da página (Hero, Services, About, etc)
- `tailwind.config.ts`: Configuração das cores (Premium Dark)
